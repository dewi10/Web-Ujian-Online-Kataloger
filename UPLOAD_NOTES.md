# Catatan Upload Repo Public

Folder ini sudah disiapkan untuk di-upload ke GitHub sebagai repo public.

Yang sudah dibersihkan dari folder ini:

- dump database
- file debug dan utilitas internal
- file backup `.old`, `.bak`, `.backup`
- konfigurasi database asli
- folder kerja lokal seperti `.git` dan `.codex`

Sebelum dijalankan:

1. Import `db_ujian_online.sql` dari folder `github-private`
2. Ubah `config/database.php` sesuai database lokal/server
3. Baru upload atau push ke GitHub
