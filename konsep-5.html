Pengembangan Modul CAT

Bank soal aktual, mekanisme ujian, auto-save, timer, penilaian, dan anti-kecurangan

Modul CAT adalah inti dari aplikasi ini — mencakup seluruh logika pengambilan soal, pengiriman jawaban, perhitungan nilai, dan perlindungan integritas ujian. Bagian ini mendokumentasikan mekanisme yang sudah berjalan, mengidentifikasi gap kritis seperti penilaian essay, dan merekomendasikan fitur anti-kecurangan yang perlu segera diimplementasikan.

5.1 Materi Soal Ujian Kompetensi Kataloger

Berdasarkan data soal aktual dalam database, ujian kompetensi kataloger mencakup enam bidang kompetensi berikut. Pemahaman terhadap distribusi materi ini penting untuk memastikan representasi soal yang seimbang di setiap sesi ujian.

5.2 Auto-Save yang Sudah Berjalan

Auto-Save Aktif: Fitur sudah berjalan di update-jawaban.php. Jawaban tersimpan saat peserta berpindah soal. Data aman meski koneksi terputus sementara — proteksi penting agar progress tidak hilang.

5.3 Mekanisme Timer

Timer adalah komponen kritis yang menentukan kapan sesi ujian berakhir. Berikut spesifikasi mekanisme timer yang berlaku, termasuk perilaku saat koneksi terputus dan tindakan otomatis saat waktu habis.

  • File Timerpages/siswa/ujian/timer.php — countdown JavaScript dengan sinkronisasi ke server
  • Sumber WaktuKolom ujian.waktu dalam menit; sesi dimulai saat peserta klik "Mulai"
  • Submit OtomatisSaat timer = 0, ujian otomatis disubmit; nilai MCQ langsung dihitung
  • Notifikasi (perlu ditambah)Peringatan visual saat sisa 10 menit (warna kuning) dan 5 menit (warna merah)

5.4 Penilaian MCQ — Sudah Otomatis

Penilaian berjalan di simpan-hasil.php: nilai dihitung berdasarkan persentase jawaban benar (is_correct = 1 di tabel jawaban), disimpan ke tabel nilai. Jika nilai ≥ nilai_kelulusan, peserta dinyatakan lulus.

5.5 Penilaian Essay — Gap Kritis

Gap Saat Ini: Ujian essay (tipe_soal = 2) menyimpan nilai awal 0. Tidak ada antarmuka untuk operator input nilai essay. Fitur penilaian essay manual harus dibangun segera sebelum ujian essay berikutnya.

Yang perlu dibangun:

  • Halaman admin: daftar peserta essay dengan status "Belum Dinilai / Sudah Dinilai"
  • Tampilkan jawaban essay yang sudah ditulis peserta di tabel hasil.essay
  • Form input nilai (0–100) per peserta per soal essay
  • Update otomatis tabel nilai setelah operator simpan

5.6 Fitur Anti-Kecurangan yang Disarankan

Menjaga integritas ujian adalah tanggung jawab sistem. Fitur-fitur berikut dapat diimplementasikan seluruhnya di sisi JavaScript frontend tanpa perubahan besar pada logika backend — cukup ditambahkan ke file ambil-soal.php.

5.8 Modul Ujian Real-Time

Modul ini adalah jantung dari pengalaman pengguna selama ujian berlangsung. Keandalan real-time dijamin melalui sinkronisasi sesi antara perangkat peserta dan server pusat:

  • Sinkronisasi SesiPolling interval pendek ke server memastikan data ujian (waktu, jawaban, status) tetap sinkron — mencegah perbedaan state antara client dan server
  • Auto-Save InteraktifJawaban disimpan secara asynchronous setiap kali peserta memilih opsi — data tidak hilang meskipun koneksi internet terganggu sementara
  • Anti-Idle MonitorSistem memantau aktivitas browser; jika tab tidak aktif atau ada indikasi ketidakhadiran mencurigakan, notifikasi peringatan dikirim ke admin
  • Peringatan Dini TimerSaat waktu tersisa ≤5 menit: warna timer berubah merah intens + animasi pulsasi untuk meningkatkan fokus dan kewaspadaan peserta
  • Auto-ResumeJika terjadi crash atau reload tidak sengaja, sistem memulihkan posisi soal terakhir dan jawaban tersimpan secara otomatis saat koneksi kembali stabil

5.10 Keamanan Integritas Modul

Prinsip Keamanan Inti: Setiap jawaban yang dikirim peserta disertai token unik yang memvalidasi sesi masih aktif dan sah. Jika token tidak valid (sesi expired, manipulasi), server menolak submission dan mencatat insiden ke audit log.
Prosedur Auto-Resume: Jika terjadi crash pada modul real-time, sistem memulihkan posisi soal terakhir dan seluruh jawaban tersimpan secara otomatis saat koneksi kembali — peserta tidak kehilangan progres pengerjaan.

5.11 Kesimpulan Modul Inti

Pernyataan Implementasi: Modul-modul inti ini dirancang untuk menciptakan lingkungan ujian yang setara, transparan, dan efisien. Dengan mengintegrasikan sistem penilaian otomatis dan mekanisme keamanan berlapis, PUSKOD BALOGHAN KEMHAN dapat memastikan kompetensi setiap kataloger diukur dengan standar seragam, objektif, dan dapat dipertanggungjawabkan di hadapan instansi pertahanan negara.
